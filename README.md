# Verity KYC demo

A polished demo KYC operations dashboard built with Flask, HTML, CSS, and vanilla JavaScript.

## Run locally

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000. OTP codes are intentionally displayed in the interface because this is a demo; data resets whenever the server restarts.
